## 報修清單緊急程度篩選

- 清單上方提供「全部／高／中／低」按鈕，預設選取「全部」；目前選取的按鈕以深綠底、白字顯示，並提供 `aria-pressed` 狀態。
- 篩選僅使用網頁已載入的最近 20 筆資料，不會因切換按鈕增加 Supabase 查詢，也不會搜尋更早的紀錄；資料仍依登記時間由新到舊排列。
- 緊急程度為「高」的標籤顯示紅色；沒有符合的資料時會顯示提示。重新整理清單後保留目前篩選。
- 本次僅調整前端與本說明，未修改資料庫、欄位或 `supabase/` 內容。

### 手機確認方式

1. 開啟此 PR 分支的網頁預覽（PR 尚未合併，正式 GitHub Pages 不會包含本次變更）。
2. 確認清單上方預設選取「全部」，依序點選「高／中／低」，清單應只顯示對應程度，且選取按鈕會變色；若沒有該程度資料，應顯示無符合資料的提示。
3. 切回「全部」確認恢復原本清單，並確認「緊急：高」標籤為紅色；窄螢幕應無水平捲動，按鈕可正常點選。
4. 若使用開發工具檢查網路請求，切換篩選不應新增 `repair_requests` 請求；點擊「重新整理」才會重新讀取清單。

## PWA 安裝與離線使用

- 在 HTTPS（GitHub Pages）或 localhost 開啟首頁；manifest、Service Worker 與圖示皆使用相對路徑，支援 `/hsin-lin/` 子目錄。
- Android／桌面 Chrome 或 Edge：可使用瀏覽器的安裝選單；瀏覽器提供安裝事件時，頁面會顯示「安裝報修登記」。iPhone：Safari → 分享 → 加入主畫面。安裝後可用獨立視窗開啟。
- 首次使用需連網並讓靜態資源快取完成，之後可離線開啟網頁；瀏覽器可能清除快取，無法保證永久離線可用。
- 離線時會顯示提示並停用送出與重新整理；報修仍須連網，不提供離線排隊、自動補送或草稿儲存，未送出內容在關閉或重新整理後可能遺失。恢復連線後請手動重新整理清單及送出。
- 快取僅限應用程式靜態資源與 Supabase CDN 程式庫，不快取報修資料、API 回應或表單內容；已開啟畫面保留的清單可能不是最新資料。
- 更新靜態檔案時同步遞增 `sw.js` 的快取版本；新版等待既有頁面關閉後啟用，請關閉此應用的所有分頁／視窗再開啟。此變更未修改資料庫。

## 各縣市特色小吃

- [各縣市特色小吃頁面](food/index.html)：整理台灣 22 個縣市共 313 種代表小吃、必吃美食、在地名店、隱藏美食與伴手禮，依縣市分組顯示介紹與常見品嚐地點。
- 可依地區（北部／中部／南部／東部／離島）、縣市與類型（主食／點心／甜品／伴手禮）篩選，並搜尋小吃、縣市或地點。
- 每個縣市標出至少兩項「⭐ 必吃」美食（共 53 項）（代表小吃一項，另加劉芋仔蛋黃芋餅、王罔麵線糊、噴水雞肉飯等名店一項，多家為米其林必比登推介），可用「只看必吃美食」快速瀏覽。
- 收錄苗栗三義賴新魁麵館、大甲康家阿媽ㄟ粉腸、臺南度小月、東海蓮心冰雞爪凍等 88 家「🏠 在地名店」，每個縣市至少三家，可用「只看在地名店」篩選。
- 另收錄景點周邊的在地美食，例如大坑老芋仔芋圓、東山棧甕缸雞、關子嶺仙嶺甕缸雞、竹山山頂甕缸雞、新社菇神、竹子湖青菜園、烏來山地美食屋，可搜尋「大坑」「甕缸雞」等關鍵字找到。
- 每個縣市另收錄一家以上「🔍 隱藏美食」（共 47 家），是觀光客較少、在地人私藏的店家（如萬華三六食粑、三重無招牌的阿北北古早味切仔麵、桃園南門市場的粉紅菜包），可用「只看隱藏美食」篩選。
- 單一靜態頁面，不連資料庫；資料僅供參考，店家營業時間與價格請以現場為準。

## 台灣一日登山步道

- [台灣一日登山步道頁面](trails/index.html)：收錄 91 條可當天來回的台灣步道，從逛老街順便走的散步路線、小百岳到百岳都有，各地區皆細分到縣市（如員林藤山步道、龍井竹坑南寮登山步道、新竹十八尖山、鹿野龍高步道、拉拉山神木群、龍過脈森林步道、臺南大凍山、佐倉步道、鎮西堡巨木群、松羅國家步道、獵鷹尖一線天）。每條步道列出距離、來回時間與爬升高度，點開「詳細資訊」可看登山口、交通、路線、附近吃買、推薦時節與注意事項。
- 可依地區（北部／中部／南部／東部）、縣市與難度（輕鬆／中等／困難）篩選，或只看「可順遊吃買」、「小百岳」的步道；可搜尋步道、地區、老街或美食，並依距離、時間、爬升排序。
- 91 條步道皆已參考網路文章查證，詳細資訊內附「參考資料」連結；來源多為旅遊網站與部落格，出發前仍請查詢官方公告。
- 單一靜態頁面，不連資料庫；距離、時間與爬升為概略值，交通班次會調整，出發前請查詢管理單位公告（例如雪山東峰須申請入園）。

## 美食與步道頁面自動更新

- GitHub Pages 允許瀏覽器暫存網頁約 10 分鐘，手機（尤其 LINE 等 App 內建瀏覽器）可能一直顯示舊版。
- `food/index.html` 與 `trails/index.html` 開啟或切回分頁時，會以不使用快取的方式向伺服器確認 `<meta name="page-version">`；版本不同就自動帶上 `?v=新版本` 重新載入。同一版本只會重新載入一次，離線時維持目前頁面。
- **修改這兩頁時，請一併更新該頁的 `page-version` 版本字串**（例如 `2026-11-16-2`），否則手機不會自動更新。
