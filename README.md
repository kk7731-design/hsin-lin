## 報修清單緊急程度篩選

- 清單上方提供「全部／高／中／低」按鈕，預設選取「全部」；目前選取的按鈕以深綠底、白字顯示，並提供 `aria-pressed` 狀態。
- 篩選僅使用網頁已載入的最近 20 筆資料，不會因切換按鈕增加 Supabase 查詢，也不會搜尋更早的紀錄；資料仍依登記時間由新到舊排列。
- 緊急程度為「高」的標籤顯示紅色；沒有符合的資料時會顯示提示。重新整理清單後保留目前篩選。
- 本次僅調整前端與本說明，未修改資料庫、欄位或 `supabase/` 內容。

### 手機確認方式

1. 開啟此 PR 分支的網頁預覽（PR 尚未合併，正式 GitHub Pages 不會包含本次變更）。
2. 確認清單上方預設選取「全部」，依序點選「高／中／低」，清單應只顯示對應程度，且選取按鈕會變色；若沒有該程度資料，應顯示無符合資料的提示。
3. 切回「全部」確認恢復原本清單，並確認「緊急：高」標籤為紅色；窄螢幕應無水平捲動，按鈕可正常點選。
4. 若使用開發工具檢查網路請求，切換篩選不應新增 `repair_requests` 請求；點擊「重新整理」才會重新讀取清單。
