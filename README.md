## 報修清單緊急程度篩選

- 清單上方提供「全部／高／中／低」按鈕，預設選取「全部」；目前選取的按鈕以深綠底、白字顯示，並提供 `aria-pressed` 狀態。
- 篩選僅使用網頁已載入的最近 20 筆資料，不會因切換按鈕增加 Supabase 查詢，也不會搜尋更早的紀錄；資料仍依登記時間由新到舊排列。
- 緊急程度為「高」的標籤顯示紅色；沒有符合的資料時會顯示提示。重新整理清單後保留目前篩選。
- 本次僅調整前端與本說明，未修改資料庫、欄位或 `supabase/` 內容。

### 手機確認方式

1. 開啟此 PR 分支的網頁預覽（PR 尚未合併，正式 GitHub Pages 不會包含本次變更）。
2. 確認清單上方預設選取「全部」，依序點選「高／中／低」，清單應只顯示對應程度，且選取按鈕會變色；若沒有該程度資料，應顯示無符合資料的提示。
3. 切回「全部」確認恢復原本清單，並確認「緊急：高」標籤為紅色；窄螢幕應無水平捲動，按鈕可正常點選。
4. 若使用開發工具檢查網路請求，切換篩選不應新增 `repair_requests` 請求；點擊「重新整理」才會重新讀取清單。

## PWA 安裝與離線使用

- 在 HTTPS（GitHub Pages）或 localhost 開啟首頁；manifest、Service Worker 與圖示皆使用相對路徑，支援 `/hsin-lin/` 子目錄。
- Android／桌面 Chrome 或 Edge：可使用瀏覽器的安裝選單；瀏覽器提供安裝事件時，頁面會顯示「安裝報修登記」。iPhone：Safari → 分享 → 加入主畫面。安裝後可用獨立視窗開啟。
- 首次使用需連網並讓靜態資源快取完成，之後可離線開啟網頁；瀏覽器可能清除快取，無法保證永久離線可用。
- 離線時會顯示提示並停用送出與重新整理；報修仍須連網，不提供離線排隊、自動補送或草稿儲存，未送出內容在關閉或重新整理後可能遺失。恢復連線後請手動重新整理清單及送出。
- 快取僅限應用程式靜態資源與 Supabase CDN 程式庫，不快取報修資料、API 回應或表單內容；已開啟畫面保留的清單可能不是最新資料。
- 更新靜態檔案時同步遞增 `sw.js` 的快取版本；新版等待既有頁面關閉後啟用，請關閉此應用的所有分頁／視窗再開啟。此變更未修改資料庫。
